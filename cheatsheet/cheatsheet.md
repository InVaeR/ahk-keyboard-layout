# Кастомная раскладка клавиатуры

## Полный список комбинаций

| Комбинация | Действие | Раздел |
|---|---|---|
| `Caps + T` | Вставить дату в формате ДД.ММ.ГГГГ | 📅 Дата и время |
| `Caps + Shift + T` | Вставить дату и время в формате ДД.ММ.ГГГГ ЧЧ:ММ | 📅 Дата и время |
| `Caps + A` | Вставить компактную дату в формате ГГГГММДД | 📅 Дата и время |
| `Caps + E` | Переключить раскладку на English (US) | 🌐 Переключение раскладки |
| `Caps + R` | Переключить раскладку на Russian | 🌐 Переключение раскладки |
| `Caps + L` | Переключить раскладку | 🌐 Переключение раскладки |
| `Caps + H` | Вставить знак рубля: ₽ | ✨ Спецсимволы |
| `Caps + .` | Вставить многоточие: … | ✨ Спецсимволы |
| `Caps + Shift + .` | Вставить знак «больше или равно»: ≥ | ✨ Спецсимволы |
| `Caps + ,` | Вставить запятую: , | ✨ Спецсимволы |
| `Caps + Shift + ,` | Вставить знак «меньше или равно»: ≤ | ✨ Спецсимволы |
| `Caps + 1` | Вставить кавычки «» и оставить курсор внутри | ✨ Спецсимволы |
| `Caps + Shift + 1` | Вставить знак градуса: ° | ✨ Спецсимволы |
| `Caps + 2` | Вставить знак «плюс-минус»: ± | ✨ Спецсимволы |
| `Caps + Shift + 2` | Вставить знак евро: $ | ✨ Спецсимволы |
| `Caps + 3` | Вставить решётку: # | ✨ Спецсимволы |
| `Caps + Shift + 3` | Вставить знак доллара: ₽ | ✨ Спецсимволы |
| `Caps + 4` | Вставить знак «примерно равно»: ≈ | ✨ Спецсимволы |
| `Caps + Shift + 4` | Вставить знак доллара: $ | ✨ Спецсимволы |
| `Caps + 5` | Вставить знак «не равно»: ≠ | ✨ Спецсимволы |
| `Caps + 6` | Вставить знак номера: № | ✨ Спецсимволы |
| `Caps + 7` | Вставить знак параграфа: § | ✨ Спецсимволы |
| `Caps + 8` | Вставить знак копирайта: © | ✨ Спецсимволы |
| `Caps + 9` | Вставить знак «зарегистрировано»: ® | ✨ Спецсимволы |
| `Caps + 0` | Вставить знак товарного знака: ™ | ✨ Спецсимволы |
| `Caps + C` | Открыть терминал PowerShell | 🚀 Запуск приложений |
| `Caps + Shift + C` | Открыть калькулятор | 🚀 Запуск приложений |
| `Caps + V` | Открыть VSCode | 🚀 Запуск приложений |
| `Caps + B` | Открыть браузер (домашняя страница) | 🚀 Запуск приложений |
| `Caps + -` | Вставить короткое тире (en dash): – | SC00C — физическая клавиша минуса: - / _ |
| `Caps + Shift + -` | Вставить длинное тире (em dash): — | SC00C — физическая клавиша минуса: - / _ |
| `Caps + Space` | Вставить неразрывный пробел (U+00A0) | SC00C — физическая клавиша минуса: - / _ |
| `Caps + Shift + Space` | Вставить тонкий пробел (U+2009) | SC00C — физическая клавиша минуса: - / _ |
| `Caps + Y` | Скопировать текущую строку в буфер обмена | 📋 Работа со строками |
| `Caps + Shift + Y` | Выделить и скопировать весь текст | 📋 Работа со строками |
| `Caps + D` | Дублировать текущую строку | 📋 Работа со строками |
| `Caps + Shift + D` | Удалить текущую строку | 📋 Работа со строками |
| `Caps + Up` | Вставить стрелку вверх: ↑ | ↑ Стрелки |
| `Caps + Down` | Вставить стрелку вниз: ↓ | ↑ Стрелки |
| `Caps + Left` | Вставить стрелку влево: ← | ↑ Стрелки |
| `Caps + Right` | Вставить стрелку вправо: → | ↑ Стрелки |

| `Caps + Numpad9` | Вставить верхний правый угол: ┐ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + Numpad4` | Вставить левое соединение: ├ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + Numpad5` | Вставить центральное соединение: ┼ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + Numpad6` | Вставить правое соединение: ┤ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + Numpad1` | Вставить нижний левый угол: └ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + Numpad2` | Вставить нижнее соединение: ┴ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + Numpad3` | Вставить нижний правый угол: ┘ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + Numpad0` | Вставить горизонтальную линию: ─ | Цифровой блок используется как панель для построения рамок и таблиц. |
| `Caps + NumpadDot` | Вставить вертикальную линию: │ | Цифровой блок используется как панель для построения рамок и таблиц. |
